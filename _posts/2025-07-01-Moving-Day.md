It's Moving Day for the blog.

Welcome to the new home, which has a lovely new domain (clutteredspaces.com) and is a [Jekyl](https://jekyllrb.com) site hosted on GitHub Pages.

The old site was on a [Wordpress](https://wordpress.com) free site.  That meant the images needed to be hosted externally so I was using [Flickr](https://www.flickr.com). However, over time Flickr started reducing the amount of images that can be hosted for free so I needed another option.  I was also struggling with uploading the images to flickr, extracting the image URL and posting into wordpress.

I'd read about static sites so I thought I would give it a go.  I really liked the idea of hosting everything in one place (github). Jekyl was a little harder to get setup than I was expected, probably because it took a while to understand how Jekyl wants things to work.  That's always the hard part with new frameworks, trying to work with it instead of against it.

So we here we are, all set up and ready to go.
